# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately by email to
**[security@packetexchange.io](mailto:security@packetexchange.io)**. Do not open a public issue, pull request or discussion for
a suspected vulnerability.

Include as much of the following as you can:

- a description of the issue and its impact;
- the affected example and commit;
- steps to reproduce, or a proof of concept;
- any suggested fix.

We aim to acknowledge reports promptly and will keep you informed as we investigate and
fix the issue. Please give us a reasonable opportunity to release a fix before disclosing
the issue publicly.

## Scope

This policy covers the code in this repository, including the mock API. Report issues with
the PacketExchange platform or API itself to the same address.

Never include a live API key, webhook secret, wallet key or customer data in a report. If a
credential has been exposed, revoke it in the PacketExchange dashboard immediately.

## Supported versions

Fixes are made on the `main` branch. There are no separately maintained releases.
